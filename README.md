# Shabbat Board — לוח שארית ישראל

לוח תפילות ומעלית שבת; GitHub Pages לאתר, Google Drive לאחסון, Google Apps Script לשכבת קריאה ציבורית ולממשק ניהול פרטי.

## מה צריך לעשות
1. העלה לשורש המאגר את `index.html` מקובץ הלוח שהוכן עבורך. קובץ זה כולל את ממשק התצוגה. **אל תעלה את `editor.html` למאגר ציבורי**; עריכת זמנים נעשית מקומית.
2. צור ב-Google Drive קובץ בשם `prayer-times.json` שתוכנו `{"format":"halachic-weekly-v1","weeks":{}}`. העתק את מזהה הקובץ מהכתובת.
3. צור פרויקט Apps Script חדש עבור **apps-script-admin** והעתק אליו `Code.gs` ואת קובץ ה-HTML בשם `Admin`. החלף `REPLACE_WITH_DRIVE_FILE_ID` במזהה הקובץ. פרוס Web app: **Execute as me** + **Only myself**. אל תפרסם את כתובת הניהול.
4. צור פרויקט Apps Script **נפרד** עבור **apps-script-public** והעתק אליו `Code.gs`. החלף את אותו מזהה קובץ. פרוס Web app: **Execute as me** + **Anyone**.
5. העתק את כתובת ה-/exec של הפריסה הציבורית בלבד אל `cloud-config.js`.
6. ודא שהמאגר ציבורי (GitHub Pages חינמי לחשבון אישי דורש בדרך כלל מאגר ציבורי), והפעל Settings → Pages → Deploy from a branch → main / root.
7. פתח את `editor.html` מקומית, ערוך זמני תפילות, יצא JSON דרך **גיבוי שבועות**, וייבא אותו בכתובת Apps Script הפרטית. העמוד הציבורי טוען את הקובץ המעודכן באופן אוטומטי ושומר עותק בדפדפן.

## בטיחות שבת
- הנתונים נטענים ונשמרים מקומית לצורך פעולה גם ללא רשת.
- בדוק ידנית את תוצאות OCR ואת תאריכי השבוע. זמני שבוע ישן אינם מקור מאומת לשבוע חדש.
- Windows יכול להינעל, להירדם או להתאתחל למרות פעולת האתר: הגדר בנפרד שינה/נעילה/עדכוני מערכת.
- בדוק טעינה מלאה, יכולת אופליין ושמירה מקומית לפני כניסת שבת.

## פרטיות ואבטחה
קוד האתר וה-API הציבורי **גלויים לכל**; זמני התפילות הם מידע ציבורי. אין לפרסם קישורי ניהול, טוקנים או פרטי חשבון. הרשאת הכתיבה נשמרת בפריסת ה-Apps Script הפרטית בלבד.
