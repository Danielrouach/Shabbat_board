# לוח שבת — משפחת רואש 🕯️

לוח שבת דיגיטלי בעברית, המיועד להצגה רציפה על מסכים בבית או בבית כנסת. הוא מציג שעון ותאריך עברי, זמני הלכה ושבת, זמני תפילות, וכן לוח פעילות נפרד למעלית שבת. זמני התפילות והמעלית ניתנים לעדכון מרחוק, בלי לשנות את קוד האתר.

**כניסה מהירה:** [לוח השבת](https://shabbat.rouach.org/) · [מסך המעלית](https://elevator.rouach.org/) · [ממשק הניהול הפרטי](https://shabbat-admin.rouach.org/) *(לבעל ההרשאה בלבד)*

> **לסוכני AI ולמפתחים:** לפני שינויי קוד קראו את [AGENTS.md](AGENTS.md). זהו מסמך ההעברה הטכני: ארכיטקטורה, חוזה הנתונים, כללים שאסור לשבור, מפת קבצים ובדיקות רגרסיה. ה־README הזה מיועד להבנה מהירה ולהפעלה שוטפת.

## מה רואים על המסכים?

| מסך | כתובת | מה הוא עושה |
|---|---|---|
| **לוח שבת ראשי** | [shabbat.rouach.org](https://shabbat.rouach.org/) | שעון, תאריך עברי/לועזי, פרשת השבוע, זמני שבת והלכה, זמני תפילות, ימי הולדת ותצוגת שלושת חלונות המעלית הקרובים |
| **מעלית שבת** | [elevator.rouach.org](https://elevator.rouach.org/) | כל חלונות פעילות המעלית ליום שישי ולשבת, הדגשת חלון פעיל ותצוגה מקדימה של השבת הקרובה |

תכונות נוספות:

- **מצב בהיר/כהה** לפי זריחה ושקיעה בחיפה, עם אפשרות לשינוי ידני וצ'קבוקס לאוטומציה (מסומן כברירת מחדל). במסך צר נוסף פס שליטה קומפקטי מתחת לכותרת ולשעון, לפני זמני התפילות; הכפתור והצ'קבוקס המקוריים נשארים גם בתחתית הלוח, וכל הפקדים מסונכרנים.
- **מצב תצוגה רספונסיבי:** במסכים גדולים שלוש עמודות. בטלפונים ובטאבלטים **לאורך** מוצגת תצוגה נוחה לגלילה (עמודה אחת בטלפון, שתיים בטאבלט), עם כותרת קומפקטית: פרשה ותאריך עברי מימין, שעון במרכז, יום/תאריך לועזי/מיקום בקצה השמאלי. בטלפונים ובטאבלטים **לרוחב** (עד 1024px) הלוח עובר אוטומטית לתצוגת קיוסק של **שלוש עמודות ללא גלילה**: הכותרת, שלושת השלישים, פס מצב התצוגה, זמני התפילות/השבת, המעלית והתחתית מותאמים יחד לגודל המסך באמצעות שינוי קנה מידה דינמי; במסך קטן במיוחד הכתב יוקטן כדי שלא ייחתך מידע. יש גם כפתור מסך מלא וניסיון לשמור על המסך פעיל באמצעות Wake Lock (בהתאם להרשאות הדפדפן ומערכת ההפעלה).
- **כותרות בשליש התפילות והשבת:** בימי חול (ראשון–חמישי, וגם ביום שישי לפני כניסת השבת) מופיעה הכותרת **״זמני תפילות״** מעל זמני בתי הכנסת, והכותרת **״זמני השבת״** ממש לפני שורות כניסת השבת וצאתה. הכותרות מעוצבות כמו **״זמני היום״** ו־**״הלכה למעשה״**; הן מוסתרות בשבת וביום טוב. זמני התפילות עצמם אינם משתנים.
- **סימולציית תאריך ושעה** לצורכי בדיקה באמצעות `Ctrl+Shift+Q` או `?qa=1`; אין להשתמש בשעת הסימולציה כזמן אמיתי.
- **חיווי עדכוני פרשות** נפרד לתפילות ולמעלית, כולל פרשת העדכון האחרון ותאריך השמירה. כשאין עדכון לפרשה הנוכחית, מופיעה הודעה **ללא הבהוב**.
- **שעות מעלית שמורות:** אם אין לוח מעלית חדש לשבוע מסוים, מוצג לוח המעלית התקין האחרון שנשמר, ולא מסך ריק. חיווי העדכון נשאר גלוי כדי שלא יתפרש בטעות כעדכון חדש.

## שליטה במצב בהיר/כהה

בלוח הראשי אפשר ללחוץ על **☀ מצב בהיר** או **☾ מצב כהה** כדי לעבור מיד למצב המוצע בכפתור. לידו נמצאת תיבת הבחירה **״אוטומטי לפי זריחה/שקיעה״**:

- **מסומנת (ברירת מחדל):** המצב נקבע לפי הנץ החמה והשקיעה בחיפה. שינוי ידני נכנס לתוקף מיד וגובר על האוטומציה **עד רענון הדף (F5)**; לאחר הרענון חוזרים למצב המחושב לפי השמש, ככל שהזמנים זמינים.
- **לא מסומנת:** המערכת נשארת במצב שבחרתם ידנית, גם אחרי רענון, בלי לשנות אותו אוטומטית לפי השמש.
- **שני מיקומי שליטה בלוח הראשי:** הכפתור והצ'קבוקס הרגילים נמצאים בתחתית. במסכים ברוחב של עד **768px**, וגם בכל מצב לרוחב עד **1024px**, מופיע עותק קומפקטי **בין שורת השעון לבין אזורי הזמנים**. במצב לרוחב מוצג רק העותק העליון כדי לחסוך מקום (פקדי התחתית המקוריים נשארים בקוד ומסונכרנים). שינוי בכל אחד מהמיקומים מתעדכן גם בשני; אין שתי העדפות נפרדות. בתצוגת דסקטופ רגילה הפס הנוסף מוסתר.

שני המסכים משתמשים במנגנון המצב המשותף שב־`theme.js` ובהעדפות דפדפן משותפות כאשר הם פועלים מאותו מקור. תצוגת המעלית עצמה לא קיבלה פס שליטה נוסף.

## איך המערכת בנויה?

האתר עצמו הוא **סטטי**: HTML, CSS ו־JavaScript ללא שרת ייעודי או תהליך Build. קובצי האתר מוגשים באמצעות **GitHub Pages**. את הנתונים המשתנים שומרים ב־**Google Drive** וקוראים באמצעות **Google Apps Script**.

```text
                 בעל הרשאה בלבד
          [פאנל ניהול — Apps Script]
                    │ שומר/מעדכן
                    ▼
           [קובץ JSON ב-Google Drive]
                    │ קורא בלבד
                    ▼
        [Apps Script ציבורי — JSONP]
                    │
              הנתונים לדפדפן
                 ┌──┴──┐
                 ▼     ▼
           [לוח ראשי] [מסך מעלית]
                 │     │
                 └──┬──┘
            localStorage (עותק מקומי)

      [GitHub Pages] מגיש את קוד שני המסכים
      [Hebcal] מספק זמני שמש, לוח שנה והבדלה
```

**חשוב:** GitHub *לא* שואב את ה־JSON מ־Drive, ופאנל הניהול *לא* מבצע Commit ל־GitHub. הדפדפן פונה לשירות הקריאה הציבורי, שמחזיר את הנתונים מהקובץ הקיים ב־Drive. למשתמשי האתר אין צורך בחשבון Google או בהרשאת גישה ישירה ל־Drive.

### מה מתעדכן ומתי?

| אירוע | לוח ראשי | מסך מעלית |
|---|---|---|
| פתיחה או רענון | בקשת נתונים חדשה | בקשת נתונים חדשה |
| סנכרון אוטומטי של זמני תפילות/מעלית | כל **15 דקות**, כשהעמוד גלוי | כל **5 דקות** |
| חזרה ללשונית פעילה | הסנכרון הבא | בקשה מיידית |
| שעון על המסך | כל שנייה | כל שנייה |

הנתונים שהתקבלו בהצלחה נשמרים גם ב־`localStorage` של הדפדפן. לכן יש אפשרות להמשיך להציג את המידע האחרון בזמן ניתוק רשת, **בתנאי שהנתונים כבר נטענו קודם במכשיר**. זה אינו תחליף לבדיקה לפני שבת.

## איך מעדכנים תפילות או מעלית?

1. נכנסים לפאנל הניהול **הפרטי** ובוחרים תאריך מתוך השבוע הרצוי.
2. לתפילות: מקלידים את הזמנים או משתמשים בזיהוי מתוך תמונה, ואז **בודקים ידנית** את התוצאה. למעלית: מדביקים את הודעת טווחי הפעילות.
3. שומרים. השירות הפרטי מאמת את הנתונים ומעדכן **רק את השדות השייכים לאותו שירות ולאותו שבוע** ב־JSON של Drive; יתר הנתונים נשמרים.
4. המסכים הציבוריים מקבלים את השינוי בסנכרון הבא. רענון ידני מבקש את הנתונים מיד.

בשמירה נשמרים בנפרד `prayersUpdatedAt` ו־`elevatorUpdatedAt`. העדכון מוצג לפי **הפרשה שבה בוצעה השמירה בפועל**, ולא בהכרח לפי תאריך השבוע שהוזן בטופס. מעבר הפרשה נועד להתבצע בצאת השבת, בהתאם למידע ההבדלה הזמין.

**התנהגות מיוחדת למעלית:** טווחי יום שישי חוזרים גם במוצאי שבת, בכפוף לזמן העצירה שהמערכת מחשבת לפי הבדלה + 30 דקות. אם נתוני ההבדלה אינם זמינים, אין להניח שזמן העצירה אומת.

## פיתוח, שינויים ופריסה

### עבודה מקומית

אפשר לשכפל את המאגר ולהגיש אותו כאתר סטטי:

```bash
git clone https://github.com/Danielrouach/Shabbat_board.git
cd Shabbat_board
python -m http.server 8000
```

פתחו `http://localhost:8000/` ללוח הראשי ו־`http://localhost:8000/elevator/` למסך המעלית. חלק מהנתונים תלויים בחיבור לאינטרנט ובשירותי Google/Hebcal.

### פרסום שינויים

- **קוד אתר (HTML/JS/CSS):** מבצעים Commit לענף `main`. GitHub Pages מוגדר להגיש את השורש של הענף; לאחר שהפריסה מסתיימת, מרעננים את האתר.
- **קוד Apps Script:** שינוי ב־GitHub **אינו** מעדכן את פרויקט Apps Script החי. יש להעתיק את קוד ה־`Code.gs`/ה־`Admin.html` המתאים לפרויקט Google הנכון, לשמור ולבצע `Deploy → Manage deployments → Edit → New version → Deploy`.
- **שירותי Google נפרדים:** פריסת הניהול היא `Execute as me` / `Only myself`; פריסת הקריאה היא `Execute as me` / `Anyone`. שניהם משתמשים באותו קובץ Drive, אבל **רק השירות הפרטי רשאי לכתוב**.
- **דומיינים והפניות:** הגדרות Cloudflare אינן נשמרות במאגר. `elevator.rouach.org` מפנה ל־`shabbat.rouach.org/elevator/`, ו־`shabbat-admin.rouach.org` מפנה לממשק הניהול של Apps Script.

**אבטחה:** אין להכניס קוד כתיבה, סיסמאות, טוקנים או הרשאות ניהול לקובצי האתר הציבוריים. השירות הציבורי מחזיר נתוני תצוגה בלבד. תאריך העדכון של המעלית לא צריך להשתנות בשמירת תפילות, ולהפך.

### לפני שבת — בדיקות חשובות

ודאו ששני המסכים נפתחו כשהרשת פעילה, שהנתונים הרצויים נשמרו ונטענו, ושזמן ההבדלה זמין לצורך מגבלות חלונות המעלית. בדקו גם שהמידע מתאים למסך ושמערכת ההפעלה אינה עומדת להירדם או להינעל. Wake Lock של הדפדפן אינו מבטיח מניעת שינה או עדכוני מערכת.

לאחר שינוי בתצוגת מובייל, בדקו גם כותרת של שורה אחת, יישור התאריך והמיקום לקצה השמאלי, נראות פס המצב הנוסף וסנכרון הכפתור והצ'קבוקס עם הפקדים שבתחתית. במצב לרוחב (טלפון או טאבלט עד 1024px) בדקו ששלושת השלישים, הכותרת, זמני התפילות/המעלית והתחתית נכנסים למסך **ללא גלילה וללא חיתוך**, כולל ביום שישי ובשבת, וששינוי אוריינטציה/מסך מלא מפעיל התאמת קנה מידה מחדש.

לבדיקות שינויים וסימולציות מפורטות ראו את [רשימת בדיקות הרגרסיה ב־AGENTS.md](AGENTS.md#7-smoke-tests--regression-checklist).

## איך התחילה הפריסה

הפרויקט התחיל כ**עמוד HTML סטטי של לוח שבת**, שהועלה למאגר `Danielrouach/Shabbat_board` ב־GitHub. בהתחלה האתר הוצג דרך כתובת **GitHub Pages** הסטנדרטית, `danielrouach.github.io/Shabbat_board/`, ללא שרת עצמאי וללא צורך ב־Build.

לאחר מכן חיברנו את הדומיין **`shabbat.rouach.org`** באמצעות GitHub Pages, רשומת CNAME והגדרות DNS ב־Cloudflare. למסך המעלית הוקם נתיב נפרד `/elevator/` וקיצור דרך **`elevator.rouach.org`**; גם ממשק הניהול קיבל קיצור דרך **`shabbat-admin.rouach.org`**, שמפנה ל־Apps Script הפרטי.

בהמשך הפרדנו בין **קוד האתר** לבין **נתוני השבוע המשתנים**: הזמנים נשמרים בקובץ JSON ב־Google Drive, פאנל Apps Script פרטי כותב אליו ושירות Apps Script ציבורי קורא ממנו. כך אפשר לעדכן תפילות או מעלית מבלי לערוך את GitHub בכל שבוע. בהמשך נוספו שמירה מקומית, חיווי עדכון לפי פרשה, מצבי תצוגה וסימולציה.

### מצב התאוששות בטלפוני Android

בדפדפני Android ברוחב עד 768px מופעלת פריסה בטוחה ללא טרנספורמציית CSS על הלוח השלם: שלושת חלקי הלוח מוצגים בזה אחר זה, עם גלילה, כדי למנוע מסך ריק ב־Galaxy. מצב זה הוא פתרון התאוששות זמני ואינו עומד עדיין בדרישת התצוגה ללא גלילה; אין להחזיר כיווץ גלובלי ללא בדיקת הדף האמיתי על מכשיר Android. במקרה של כשל בטעינת נתונים, מסך הטעינה מוסתר ומוצגת הודעת שגיאה בתחתית.
