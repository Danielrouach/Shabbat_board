# Shabbat Board — לוח שארית ישראל

לוח תפילות ומעלית שבת; GitHub Pages לאתר, Google Drive לאחסון, Google Apps Script לשכבת קריאה ציבורית ולממשק ניהול פרטי.

## מה צריך לעשות
1. העלה לשורש המאגר את `index.html` מקובץ הלוח שהוכן עבורך. קובץ זה כולל את ממשק התצוגה. **אל תעלה את `editor.html` למאגר ציבורי**; עריכת זמנים נעשית מקומית.
2. צור ב-Google Drive קובץ בשם `prayer-times.json` שתוכנו `{"format":"halachic-weekly-v1","weeks":{}}`. העתק את מזהה הקובץ מהכתובת.
3. צור פרויקט Apps Script חדש עבור **apps-script-admin** והעתק אליו `Code.gs` ואת קובץ ה-HTML בשם `Admin`. החלף `REPLACE_WITH_DRIVE_FILE_ID` במזהה הקובץ. פרוס Web app: **Execute as me** + **Only myself**. אל תפרסם את כתובת הניהול.
4. צור פרויקט Apps Script **נפרד** עבור **apps-script-public** והעתק אליו `Code.gs`. החלף את אותו מזהה קובץ. פרוס Web app: **Execute as me** + **Anyone**.
5. העתק את כתובת ה-/exec של הפריסה הציבורית בלבד אל `cloud-config.js`.
6. ודא שהמאגר ציבורי (GitHub Pages חינמי לחשבון אישי דורש בדרך כלל מאגר ציבורי), והפעל Settings → Pages → Deploy from a branch → main / root.
7. פתח את `editor.html` מקומית, ערוך זמני תפילות, יצא JSON דרך **גיבוי שבועות**, וייבא אותו בכתובת Apps Script הפרטית. העמוד הציבורי טוען את הקובץ המעודכן באופן אוטומטי ושומר עותק בדפדפן.

## בטיחות שבת
- הנתונים נטענים ונשמרים מקומית לצורך פעולה גם ללא רשת.
- בדוק ידנית את תוצאות OCR ואת תאריכי השבוע. זמני שבוע ישן אינם מקור מאומת לשבוע חדש.
- Windows יכול להינעל, להירדם או להתאתחל למרות פעולת האתר: הגדר בנפרד שינה/נעילה/עדכוני מערכת.
- בדוק טעינה מלאה, יכולת אופליין ושמירה מקומית לפני כניסת שבת.

## פרטיות ואבטחה
קוד האתר וה-API הציבורי **גלויים לכל**; זמני התפילות הם מידע ציבורי. אין לפרסם קישורי ניהול, טוקנים או פרטי חשבון. הרשאת הכתיבה נשמרת בפריסת ה-Apps Script הפרטית בלבד. 


## שני מסכי תצוגה (ללא גלילה בשבת)
- לוח ראשי: https://danielrouach.github.io/Shabbat_board/ — כולל שלושה חלונות מעלית קרובים בראש עמודת שבת, מתעדכן אוטומטית.
- מסך מעלית נפרד: https://danielrouach.github.io/Shabbat_board/elevator.html — מציג את כל הטווחים של יום שישי או שבת, במלואם, בגריד ללא גלילה; מדגיש חלון פעיל ומחזיק עותק מקומי. פתח לפני שבת במסך השני.
- בעמוד הניהול הפרטי, גרור JPG/PNG של לוח התפילות, בדוק את השעות שזוהו ושמור. הדבק בנפרד את הודעת המעלית. אין צורך ב-JSON ידני.
- **תיקוני Apps Script ב-GitHub אינם מתעדכנים אוטומטית בפריסת Google**: יש להעתיק את `apps-script-admin/Admin.html` לפרויקט Apps Script ולפרוס New version. יש לבצע זאת רק לפני שבת.
- OCR של מנחה וערבית בחול מבצע ניסיון נוסף לפי עמודת השעות בתבנית המוכרת. זו הצעה בלבד; חובה לוודא מול התמונה לפני שמירה.

## שחרית, שני מסכים וסימולציה (נובמבר 2026)
- בלוח הראשי: שחרית בשבת ב**הרב אליהו אבוחצרא** 08:00; בחול ב**אור וישועה** 07:10 וב**רמב"ם** 07:00 ו-08:00. הזמנים קבועים, ללא צורך ב-Admin.
- בלוח הראשי: שלוש משבצות מעלית קרובות בראש עמודת השבת, גם במוצאי שבת עד 30 דקות אחרי זמן ההבדלה של Hebcal.
- בדף `elevator.html`: כל חלונות המעלית של היום במסך אחד. חלונות ערב שבת חוזרים גם במוצאי שבת, כשהטווח האחרון נחתך עד 30 דקות אחרי צאת שבת.
- דף המעלית: `Ctrl+Shift+Q` מציג בקרות סימולציה של תאריך ושעה לפי שעון ישראל; איפוס מחזיר לזמן אמיתי; `?qa=1` פותח את הבקרות מראש.
- זמן ההבדלה נשמר בדפדפן מראש דרך Hebcal (חיפה, אותו מודל כמו הלוח הראשי). לפתוח את שני המסכים עם אינטרנט לפני כניסת שבת; אם זמן ההבדלה אינו שמור, הדף מציג אזהרה ואינו יכול להבטיח את מועד העצירה המדויק.
- כיבוי מסך/נעילת Windows/אתחולים אינם ניתנים למניעה מוחלטת מתוך האתר. יש להגדיר את מערכת ההפעלה בנפרד.
